# 子问题 2：每工件 ≥10 件，最大化总收益

> 求解算法：两阶段 EMS 贪心构造 + 多试次随机搜索

---

## 一、数学模型

### 1. 集合与索引

$$
\begin{aligned}
M &= \{L01, L02, L03\} &&\text{原材料类型} \\[2pt]
B_m &= \{1,2,\ldots,5\} &&\text{类型 $m$ 的原材料块编号} \\[2pt]
B &= \bigcup_{m \in M} B_m \quad (|B|=15) &&\text{全部原材料块} \\[2pt]
J &= \{J01, J02, \ldots, J07\} &&\text{工件类型} \\[2pt]
O &= \{1,2,3,4,5,6\} &&\text{摆放姿态 (长宽高排列)} \\[2pt]
K_j &\quad &&\text{工件 $j$ 的实例编号}
\end{aligned}
$$

### 2. 参数

$$
\begin{aligned}
(L_m, W_m, H_m) &\quad \text{原材料 $m$ 尺寸} &\quad V_m &= L_m \cdot W_m \cdot H_m &&\text{原材料体积} \\[2pt]
(l_j, w_j, h_j) &\quad \text{工件 $j$ 原始尺寸} &\quad v_j &= l_j \cdot w_j \cdot h_j &&\text{工件体积} \\[2pt]
(l'_j, w'_j, h'_j)^{(o)} &\quad \text{姿态 $o$ 下的实际占用尺寸} &\quad p_j &\quad &&\text{工件收益}
\end{aligned}
$$

### 3. 决策变量

$$
\begin{aligned}
place_{b,j,k,o} &\in \{0, 1\} &&\text{工件 $j$ 的第 $k$ 个实例以姿态 $o$ 是否放入块 $b$} \\[2pt]
x_{b,j,k} &\geq 0 &&\text{摆放 $x$ 坐标} \\[2pt]
y_{b,j,k} &\geq 0 &&\text{摆放 $y$ 坐标} \\[2pt]
z_{b,j,k} &\geq 0 &&\text{摆放 $z$ 坐标 (刀具进给方向)}
\end{aligned}
$$

### 4. 约束条件

**(a) 最低产量约束**

$$
\sum_{b \in B} \sum_{k \in K_j} \sum_{o \in O} place_{b,j,k,o} \geq 10, \quad \forall j \in J
$$

**(b) 空间边界约束** (工件不能超出原材料范围)

$$
\begin{cases}
x_{b,j,k} + l'_j \leq L_m \\[2pt]
y_{b,j,k} + w'_j \leq W_m \\[2pt]
z_{b,j,k} + h'_j \leq H_m
\end{cases}
$$

**(c) 不重叠约束 (析取约束)**

对同一块 $b$ 中任意两个不同工件实例，至少满足以下六个条件之一：

$$
\begin{aligned}
&x + l' \leq x' &&\lor &&x' + l'' \leq x &&\lor \\[2pt]
&y + w' \leq y' &&\lor &&y' + w'' \leq y &&\lor \\[2pt]
&z + h' \leq z' &&\lor &&z' + h'' \leq z
\end{aligned}
$$

> 含义：两个长方体在三维空间中不重叠，当且仅当它们在 $x$、$y$ 或 $z$ 轴的至少一个方向上完全分离。

### 5. 目标函数

$$
\max \quad \Pi = \sum_{b \in B} \sum_{j \in J} \sum_{k \in K_j} \sum_{o \in O} p_j \cdot place_{b,j,k,o}
$$

> 等价表述：在满足每种工件至少 10 件的前提下，最大化所有已摆放工件的总收益。

### 6. 复杂度

带析取约束的 **3D 装箱 MILP**，属于**强 NP-hard**。15 块原材料 + 数百工件 → 精确算法 (分支定界/MILP求解器) 计算不可行。

---

## 二、求解算法：两阶段 EMS + 多试次

### 2.1 阶段 1：必须品优先打包

- $10 \times 7 = 70$ 件必须品，按**体积降序**排列 (大件优先)
- 姿态采用轮换策略 (各工件均匀使用 6 种姿态)
- EMS 顺序打包到 15 块料中 (大块优先)
- 确保所有必须品都能放入

### 2.2 阶段 2：利润填充

- 估计剩余空间容量，生成额外候选工件池
- 按**利润密度降序**排列
- EMS 顺序填充剩余空间
- 合并碎片空间 + 二次填充 + 缝隙填充 (小尺寸工件优先)

### 2.3 多试次搜索

- 试次 $1\sim10$：姿态轮换 (确定性)
- 试次 $11\sim40$：姿态随机 (探索性)
- 保留全局最优解

### 2.4 EMS 核心规则 (Best-Fit)

维护一个**互不重叠的空闲空间列表**。每次放置工件时：

| 步骤 | 操作 |
|------|------|
| (1) | 在所有可容纳此工件的空间中，找 $\min[(空间.dx - 工件.dx) + (空间.dy - 工件.dy) + (空间.dz - 工件.dz)]$ 的空间 |
| (2) | 在该空间的**原点角落**放置工件 |
| (3) | 从该空间切除工件体积，生成最多 **6 个子空间** (下方/上方/前方/后方/左方/右方) |
| (4) | 检查**所有其他空间**是否与新工件相交，若相交则切除相交部分 |
| (5) | 周期性合并相邻空间 (面完全对齐 + 另两轴重合) 以**反碎片化** |

### 2.5 算法流程图

```text
┌──────────────────────────────────────────┐
│  阶段 1: 必须品打包                        │
│  ┌─────────────────────────────────────┐ │
│  │ 70 件必须品，体积降序，轮换姿态        │ │
│  │    ↓ EMS 贪心                        │ │
│  │ 15 块料已部分填充                     │ │
│  └─────────────────────────────────────┘ │
│                  ↓                       │
│  阶段 2: 利润填充                         │
│  ┌─────────────────────────────────────┐ │
│  │ 利润候选工件，利润密度降序              │ │
│  │    ↓ EMS 贪心 + 合并 + 缝隙填充       │ │
│  │ 最终摆放方案 → 总利润                 │ │
│  └─────────────────────────────────────┘ │
│                  ↓                       │
│  重复 40 次 (姿态策略变化) → 保留最优     │
└──────────────────────────────────────────┘
```

## 三、算法特点

| 维度 | 说明 |
|------|------|
| **算法类型** | 构造启发式 (Constructive Heuristic) |
| **核心机制** | EMS (Empty Maximal Spaces) 空间管理 |
| **选择规则** | Best-Fit 贪心 (最紧密适配) |
| **搜索策略** | 两阶段分解 + 多试次随机重启 |
| **全局性** | 局部贪心，无回溯，靠多试次弥补 |
| **时间复杂度** | $O(T \cdot N \cdot S)$ 其中 $T$=试次, $N$=工件数, $S$=空间数 |
| **优势** | 速度快、确定性高、必须品保证可行 |
| **劣势** | 无法逃离局部最优、阶段割裂 |
