# 子问题 2：每工件 ≥10 件，最大化总收益

> 求解算法：多策略两阶段 EMS 贪心构造 + 破坏-重建迭代局部搜索 (Iterated Local Search)

---

## 一、数学模型

### 1. 集合与索引

$$
\begin{aligned}
M &= \{L01, L02, L03\} &&\text{原材料类型} \\[2pt]
B_m &= \{1,2,\ldots,5\} &&\text{类型 $m$ 的原材料块编号} \\[2pt]
B &= \bigcup_{m \in M} B_m \quad (|B|=15) &&\text{全部原材料块} \\[2pt]
J &= \{J01, J02, \ldots, J07\} &&\text{工件类型} \\[2pt]
O &= \{1,2,3,4,5,6\} &&\text{摆放姿态 (长宽高排列)} \\[2pt]
K_j &\quad &&\text{工件 $j$ 的实例编号}
\end{aligned}
$$

### 2. 参数

$$
\begin{aligned}
(L_m, W_m, H_m) &\quad \text{原材料 $m$ 尺寸} &\quad V_m &= L_m \cdot W_m \cdot H_m &&\text{原材料体积} \\[2pt]
(l_j, w_j, h_j) &\quad \text{工件 $j$ 原始尺寸} &\quad v_j &= l_j \cdot w_j \cdot h_j &&\text{工件体积} \\[2pt]
(l'_j, w'_j, h'_j)^{(o)} &\quad \text{姿态 $o$ 下的实际占用尺寸} &\quad p_j &\quad &&\text{工件收益}
\end{aligned}
$$

### 3. 决策变量

$$
\begin{aligned}
place_{b,j,k,o} &\in \{0, 1\} &&\text{工件 $j$ 的第 $k$ 个实例以姿态 $o$ 是否放入块 $b$} \\[2pt]
x_{b,j,k} &\geq 0 &&\text{摆放 $x$ 坐标} \\[2pt]
y_{b,j,k} &\geq 0 &&\text{摆放 $y$ 坐标} \\[2pt]
z_{b,j,k} &\geq 0 &&\text{摆放 $z$ 坐标 (刀具进给方向)}
\end{aligned}
$$

### 4. 约束条件

**(a) 最低产量约束**

$$
\sum_{b \in B} \sum_{k \in K_j} \sum_{o \in O} place_{b,j,k,o} \geq 10, \quad \forall j \in J
$$

**(b) 空间边界约束** (工件不能超出原材料范围)

$$
\begin{cases}
x_{b,j,k} + l'_j \leq L_m \\[2pt]
y_{b,j,k} + w'_j \leq W_m \\[2pt]
z_{b,j,k} + h'_j \leq H_m
\end{cases}
$$

**(c) 不重叠约束 (析取约束)**

对同一块 $b$ 中任意两个不同工件实例，至少满足以下六个条件之一：

$$
\begin{aligned}
&x + l' \leq x' &&\lor &&x' + l'' \leq x &&\lor \\[2pt]
&y + w' \leq y' &&\lor &&y' + w'' \leq y &&\lor \\[2pt]
&z + h' \leq z' &&\lor &&z' + h'' \leq z
\end{aligned}
$$

### 5. 目标函数

$$
\max \quad \Pi = \sum_{b \in B} \sum_{j \in J} \sum_{k \in K_j} \sum_{o \in O} p_j \cdot place_{b,j,k,o}
$$

> 等价表述：在满足每种工件至少 10 件的前提下，最大化所有已摆放工件的总收益。

### 6. 复杂度

带析取约束的 **3D 装箱 MILP**，属于**强 NP-hard**。15 块原材料 + 数百工件 → 精确算法 (分支定界/MILP求解器) 计算不可行。

## 二、原版算法的问题诊断

原版两阶段 EMS 贪心算法（`ems_solver_subproblem2.py`）存在三个根本性缺陷：

| 问题 | 根因 | 影响 |
|------|------|------|
| **两阶段割裂** | Phase 1（必须品按体积降序）→ Phase 2（利润品按利润密度降序）硬分割。Phase 1 中 J07（120×20×20，体积最小但利润密度最高）排在最后，轮到它时空间已被大件碎片化 | J07 仅产出 45 件（理论上限 750+） |
| **Best-Fit 偏好大件** | 评分函数为绝对间隙 $(dx-l)+(dy-w)+(dz-h)$。大工件在空旷空间中拥有更小的绝对间隙 → 小件在大块上竞争不过大件 | J01/J02 在大块上被 J05/J06 挤出 |
| **无局部搜索** | 贪心放置后永不移动，无法逃离局部最优 | 构造质量 = 最终质量，无改进空间 |

---

## 三、新求解算法：多策略两阶段 EMS + 迭代局部搜索

### 3.1 核心设计原则

1. **保留两阶段框架** — Phase 1 只放必须品保证可行性（≥10 约束），这是被实践验证的正确架构
2. **Phase 1 多策略排序** — 变化必须品的排列顺序（体积 / 最长边 / 利润密度 / 混合 / 随机），增加搜索多样性，让 J07 等长条工件有机会在先
3. **Best-Fit 间隙度量** — 保留全局扫描 + 最紧密贴合，这是最有效的 3D 贪心机制
4. **破坏-重建 (Destroy-and-Repair)** — 迭代移除低利润密度工件后重新填充，实现局部最优逃离
5. **大候选池** — 每种工件生成充足候选（按 `max(60, 剩余体积/工件体积 × 0.7)` 估计），确保 Best-Fit 有足够选择空间

### 3.2 算法流程图

```text
┌──────────────────────────────────────────────────┐
│  外循环: 48 次多策略构造试验                        │
│  ┌─────────────────────────────────────────────┐ │
│  │  策略: volume / ld / pd / hybrid / random    │ │
│  │         ↓                                   │ │
│  │  Phase 1: 必须品 (70 件)                     │ │
│  │    按策略排序 → EMS 贪心 → 15 块部分填充      │ │
│  │         ↓                                   │ │
│  │  Phase 2: 利润候选 (≈3800 件)                │ │
│  │    利润密度降序 → EMS 贪心 + 合并 + 缝隙填充   │ │
│  │         ↓                                   │ │
│  │  验证 ≥10 约束 → 保留最优构造解               │ │
│  └─────────────────────────────────────────────┘ │
│                    ↓                             │
│  ┌─────────────────────────────────────────────┐ │
│  │  迭代局部搜索 (800 轮)                        │ │
│  │  for iter in 1..800:                        │ │
│  │    销毁: 移除 ≈15% 非必须品 (偏置低利润密度)   │ │
│  │    重建: 保留工件打包到空块 + 填充预生成池      │ │
│  │    if 利润改善 → 接受; else → 回滚             │ │
│  └─────────────────────────────────────────────┘ │
│                    ↓                             │
│  输出: 全局最优方案                                │
└──────────────────────────────────────────────────┘
```

### 3.3 EMS 核心规则 (Best-Fit)

维护**互不重叠的空闲空间列表**。每次放置工件时：

| 步骤 | 操作 |
|------|------|
| (1) | 扫描全部候选工件，对每个工件在所有空间中找到最佳适配位置 |
| (2) | 评分函数: $\min[(空间.dx - 工件.dx) + (空间.dy - 工件.dy) + (空间.dz - 工件.dz)]$ |
| (3) | 全局选择间隙最小的 (工件, 空间) 组合 |
| (4) | 在空间原点角落放置工件 |
| (5) | 从该空间切除工件体积，生成最多 6 个子空间 |
| (6) | 检查所有其他空间是否与新工件相交，若相交则切除相交部分 |
| (7) | 三轴方向 (x/y/z) 周期性合并相邻空间以**反碎片化** |

### 3.4 Phase 1 多策略变体

| 策略 ID | Phase 1 排序 | 特点 |
|---------|-------------|------|
| `two_phase_volume` | 必须品按体积降序 | 与原版一致，大件优先填充 |
| `two_phase_ld` | 必须品按最长边降序 | J07(120mm) 优先，长件在空间规整时放置 |
| `two_phase_pd` | 必须品按利润密度降序 | 高利润必须品优先 |
| `two_phase_hybrid` | 体积 × 利润密度¹/³ | 大件 + 利润的折中 |
| `two_phase_random` | 随机打乱 | 最大探索多样性 |

### 3.5 破坏-重建算子 (D&R)

| 组件 | 设计 |
|------|------|
| **破坏策略** | 70% 概率偏置低利润密度工件，30% 概率完全随机 |
| **破坏比例** | 当前非必须品数量的 15% |
| **重建** | 保留工件按利润密度降序重新打包到空块 |
| **填充** | 预生成填充池 (~2000 件，利润密度降序)，全部迭代复用 |
| **接受准则** | 仅接受严格改善 (Hill Climbing) |

## 四、算法特点分析

| 维度 | 说明 |
|------|------|
| **算法类型** | 构造启发式 + 迭代局部搜索 (Constructive Heuristic + ILS) |
| **核心机制** | EMS (Empty Maximal Spaces) 空间管理 |
| **选择规则** | Best-Fit 贪心 (全局最紧密贴合) |
| **搜索策略** | 多策略构造 (48 次) + 破坏-重建 (800 轮) |
| **全局性** | ILS 提供局部最优逃离能力，弥补贪心构造的短视 |
| **时间复杂度** | 构造: $O(T \cdot N \cdot \bar{S})$, ILS: $O(I \cdot D \cdot \bar{N} \cdot \bar{S})$ |
| **上界** | 体积背包松弛: **843,840** |
| **优势** | 可行性保证、ILS 逃离局部最优、多策略多样性 |
| **劣势** | 随机性导致结果波动、ILS 收敛无理论保证 |

## 五、为什么 ILS 有效

原版两阶段贪心：构造解质量 = 最终解质量（无改进机制）。

本算法在构造解之上叠加 800 轮破坏-重建：
- 每轮移出 15%（≈50-80 件）的低利润密度工件 → 释放约 7M 体积
- 保留工件重新打包 + 填入高利润新候选 → 探索邻域空间
- 仅接受改善 → 目标函数单调递增

ILS 贡献约 **+68,000 利润**（构造最优 660,160 → 最终 727,990）。

### J07 为何从 45 → 230

J07（120×20×20）利润密度最高 (0.01125) 但形状为细长条（长宽比 6:1），需要 ≥120mm 的空间维度。

- **原版**：Phase 1 按体积降序，J07 排在最后。75% 的空间已被大件碎片化，120mm+ 的连续空间稀缺 → 仅 45 件
- **新版**：`two_phase_ld` 策略将 J07 排在最前（最长边 120mm 最大），在空间规整时大量放置。ILS 进一步通过移除低利润工件为 J07 腾出空间 → 230 件

| 工件 | 尺寸 | 利润密度 | 原版 | 本算法 | Δ |

> 核心改进：高利润密度工件 (J07, J05) 大量增产，低利润密度工件 (J04, J06) 让步。这正是利润最大化目标的正确方向。

### 6.3 上界分析

理论利润上界（体积背包松弛，忽略几何约束）＝ **843,840**。

$$
\begin{aligned}
\Pi_{UB} &= \underbrace{81,900}_{\text{必须品 70 件}} \;+\; \underbrace{761,940}_{\text{J07 × 1411 (纯体积允许)}} = 843,840 \\[6pt]
\Pi_{best} &= 727,990 \\[4pt]
\text{Gap} &= 843,840 - 727,990 = 115,850 \quad (13.7\%)
\end{aligned}
$$

剩余差距主要来自：
1. **几何约束** — J07 不可能完美填充所有体积（长宽比 6:1 的细长条形状限制），这是最大因素
2. **体积效率权衡** — J05/J04 等大工件占用体积效率低于 J07，但利润密度较低，形成天然 trade-off
3. **块间废料** — 不同块尺寸的不可整除性导致天然材料浪费
